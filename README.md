# Renato Matos Style

Quero criar um site profissional para a **Renato Matos Barbearia** usando as imagens e a logo que estou anexando.

IMPORTANTE: utilize as imagens reais que estou enviando no site. Não substitua essas imagens por fotos genéricas de banco de imagens.

Analise visualmente as imagens anexadas e construa a identidade visual do site a partir delas.

### Identidade visual

A marca tem uma estética masculina, profissional, elegante e moderna.

A identidade deve utilizar principalmente:

- azul-marinho

- preto

- branco

- cinza escuro

- pequenos detalhes em azul

A logo "Renato Matos Barbearia" deve ser preservada e utilizada sem alterar seu desenho.

Não quero um site com aparência exageradamente futurista, tecnológica ou cheia de efeitos.

Quero uma aparência de barbearia premium, mas acessível e autêntica.

O site deve transmitir:

- profissionalismo

- confiança

- qualidade

- cuidado com o cliente

- experiência

- estilo masculino

### Estrutura do site

Crie uma página inicial completa, responsiva e profissional.

#### HEADER

Utilize a logo da Renato Matos Barbearia no lado esquerdo.

Menu:

- Início

- Sobre

- Serviços

- Galeria

- Avaliações

- Localização

Adicionar botão destacado:

"AGENDAR HORÁRIO"

O header deve permanecer fixo durante a navegação.

#### HERO

Utilize a primeira foto enviada, mostrando o cliente com o corte e barba, como imagem principal.

A foto deve ocupar uma área grande da tela.

Faça um tratamento visual escuro e elegante na imagem para permitir a utilização de texto por cima sem prejudicar a fotografia.

Texto principal:

"SEU ESTILO.

NOSSO TRABALHO."

Subtexto:

"Cortes, barba e estilo feitos com atenção aos detalhes."

Botões:

"AGENDAR HORÁRIO"

"VER SERVIÇOS"

A composição deve parecer uma campanha profissional de barbearia, e não um simples banner.

#### SOBRE A BARBEARIA

Utilize a logo da Renato Matos Barbearia.

Criar uma seção apresentando a empresa.

Texto inicial:

"Mais do que um corte, uma experiência."

Criar um texto profissional explicando que a barbearia valoriza qualidade, atendimento e atenção aos detalhes.

Não invente informações específicas sobre a história da empresa que não foram fornecidas.

Deixe informações como número de anos de existência, quantidade de clientes e outros dados facilmente editáveis.

#### SERVIÇOS

Criar cards elegantes para:

Corte Masculino

Corte + Barba

Barba

Acabamento

Corte Infantil

Sobrancelha

Cada card deve conter:

- nome

- descrição curta

- preço editável

- botão "Agendar"

Não invente preços definitivos. Use valores de exemplo claramente identificados como editáveis.

#### GALERIA

Criar uma galeria utilizando PRINCIPALMENTE as fotos reais que estou enviando.

Não distorça as imagens.

Use diferentes proporções e cortes para criar uma composição visual interessante.

A galeria deve mostrar:

- cortes

- barba

- detalhes do trabalho

- atendimento

Adicionar efeito sutil de zoom ao passar o mouse.

No celular, a galeria deve se adaptar perfeitamente.

#### DESTAQUE DA MARCA

Utilize a imagem que contém a frase:

"VOCÊ AGENDA, A GENTE CAPRICHA"

Essa imagem deve receber uma seção própria de destaque.

Não recrie a arte com HTML.

Utilize a imagem original fornecida.

O objetivo é transformar essa arte em uma chamada visual para o agendamento.

Adicionar botão:

"AGENDAR AGORA"

#### PROCESSO / EXPERIÊNCIA

Utilize a foto em que o barbeiro está realizando o corte.

Criar uma seção mostrando a experiência do atendimento.

Estrutura:

"Do primeiro contato ao acabamento."

Criar 3 etapas:

01 — Escolha seu serviço

02 — Agende seu horário

03 — Sente na cadeira e aproveite

Utilizar a fotografia ao lado do conteúdo.

#### AVALIAÇÕES

Criar uma seção moderna para avaliações de clientes.

Não invente avaliações reais.

Use textos demonstrativos claramente identificados como conteúdo temporário que poderá ser substituído pelas avaliações reais posteriormente.

#### LOCALIZAÇÃO

Criar uma seção para endereço, horário de funcionamento, telefone e WhatsApp.

Deixar campos editáveis para que eu possa inserir os dados reais da barbearia.

Adicionar botão:

"COMO CHEGAR"

#### AGENDAMENTO

Criar uma experiência simples de agendamento.

O cliente deve conseguir selecionar:

- serviço

- barbeiro

- data

- horário

Depois mostrar:

"CONFIRMAR PELO WHATSAPP"

Ao clicar, criar uma mensagem automática com as informações escolhidas.

Deixar o número de WhatsApp como uma variável fácil de editar.

Não criar login nem sistema complexo de usuários nesta primeira versão.

### DESIGN

Quero um visual premium e moderno.

Utilize:

- fundo escuro em algumas seções

- fundo branco em outras

- azul-marinho como cor de identidade

- tipografia elegante

- bastante espaço entre os elementos

- bordas discretamente arredondadas

- sombras sutis

- animações suaves

- microinterações nos botões

- transições elegantes

Não exagere nas animações.

A fotografia deve ser um dos elementos principais do site.

### RESPONSIVIDADE

O site precisa ficar excelente em:

- celular

- tablet

- notebook

- desktop

No celular:

- menu hamburger

- botões grandes

- imagens proporcionais

- textos bem dimensionados

- agendamento fácil

- botão de WhatsApp facilmente acessível

### IMPORTANTE SOBRE AS IMAGENS

Use as imagens originais que estou enviando.

Não:

- altere os rostos das pessoas

- gere novos cortes artificialmente

- substitua as fotografias por imagens de IA

- distorça as proporções

- aplique filtros exagerados

Pode fazer apenas ajustes de:

- enquadramento

- crop

- brilho

- contraste

- sobreposição escura para melhorar legibilidade

A logo também deve ser utilizada como fornecida.

O resultado final deve parecer um site real e profissional desenvolvido especificamente para a **Renato Matos Barbearia**, e não um template genérico criado por IA.
